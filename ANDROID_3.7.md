# StreamwearsIRL Android 3.7 beta

Android 3.7 updates Studio, Destinations, AI, Live and Settings to follow the iPhone app’s layout: black backgrounds, mint controls, rounded cards and floating navigation.

Studio keeps native camera/glasses preview, account connections, per-destination switches, chat, preview controls and Go live. Settings preserves advanced controls and adds a local progress backup. AI supports selecting or taking a photo for on-device image labels and Latin text recognition, typed translation and Android speech input when available. Ask uses the Streamwears online service; Apple’s on-device AI is not included.

Meta glasses use Developer Mode in Meta AI, with APPLICATION_ID=0 and CLIENT_TOKEN=0. No registered-channel invitation is needed for this route. This is a beta/testing connection, not Meta production approval.

Install this signed update over the existing app to retain saved accounts. Actual glasses performance and provider broadcasts require physical-device testing; emulator checks do not establish zero dropped frames or full iOS parity.

Developer Mode setup and downloads are in the [README](README.md). Instagram manual URL/key setup remains available from Destinations.
