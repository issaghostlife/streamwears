## Adding future notes

Keep versioned notes in this folder, with the newest entry first in the relevant index:

- iPhone: `ios/<version>-<build>.md`
- Android: `android/<version>.md`
- Android publishing guide: [android/PUBLISHING.md](android/PUBLISHING.md)

Keep the repository’s main page focused on the app and its download links. Add new version files here rather than placing them at the repository root. Public notes should describe user-visible changes, availability and feedback requests. Keep app source, credentials and private implementation details out of this repository.

Published [GitHub Releases](https://github.com/issaghostlife/streamwears/releases) also supply the in-app What’s New feed. Use the same short, user-facing notes there; keep the folder index up to date.
