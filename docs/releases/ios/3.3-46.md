# Streamwears iOS 3.3 (46)

Get this beta through [TestFlight](https://testflight.apple.com/join/Ee36dYF9) when build 46 appears for your account.

- Restored Instagram sign-in.
- Use compatible Meta glasses for audio input and output in Clip Studio.
- Open encrypted projects more easily from the Cloud library.
- See fundraising totals in a smaller Support card in Settings.

Trying compatible Meta glasses? Enable **Developer Mode** in Meta AI, install or update **Device Access Toolkit** on the glasses, then open **Studio**, select **Meta Glasses**, and tap **Start preview**. Approve camera access if prompted.
