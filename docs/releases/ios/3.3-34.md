# Streamwears iOS 3.3 (34)

Submitted for external TestFlight review. [Open TestFlight](https://testflight.apple.com/join/Ee36dYF9) to see which build you can install.

- In Studio, choose **Audio only**. The waveform follows your mic. Turn on **Face Cam** to replace your profile photo with the front camera.
- In Clip Studio, start from a saved live or imported clip. Pick a **Pro Studio** template for an editable cut. Select a clip and choose **More → Detach audio** to edit its sound separately.
- Edit captions inline. Full Access removes Streamwears branding from the live feed.
- If Instagram asks you to sign in again, reconnect your saved account in **Destinations**.
- Assist uses shorter labels by default. Find your glasses under **Settings → Meta glasses → Find device**.

Please try **Start Preview** with compatible Meta glasses. Enable **Developer Mode** in Meta AI and install or update the **Device Access Toolkit** on your glasses first.
