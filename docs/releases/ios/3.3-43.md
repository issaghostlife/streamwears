# Streamwears iOS 3.3 (43)

Build 43 is available to Streamwear Beta testers through [TestFlight](https://testflight.apple.com/join/Ee36dYF9).

- Improved glasses preview when stopping and restarting.
- Updated Studio controls for narrow and wide displays.
- Switch to the iPhone camera if a glasses preview is interrupted.

### First-time glasses setup

1. Pair your compatible glasses in the **Meta AI** app.
2. In Meta AI, open **Settings → App Info**. Tap the **App version** number five times and turn on **Developer Mode**.
3. Install or update **Device Access Toolkit** on your glasses from Meta AI.
4. Open **Streamwears → Studio**, select **Meta Glasses**, and tap **Start Preview**. Approve camera access if Meta AI asks.
