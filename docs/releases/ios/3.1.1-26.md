# Streamwears 3.1.1 (26)

[Back to release notes](../README.md) · [Get Streamwears on TestFlight](https://testflight.apple.com/join/Ee36dYF9)

Build 26 is available to the Streamwear Beta group through TestFlight.

- More resilient live recovery when switching apps or the camera reconnects.
- Edit saved live clips in Clip Studio with trim, split, reorder, titles, captions, audio, and export.
- Connect separate TikTok accounts; unavailable viewer counts no longer appear as zero.

Please try returning to Streamwears during a live, editing and exporting a saved clip, and connecting a second TikTok account. For glasses, enable Developer Mode in Meta AI, install or update the Device Access Toolkit on the glasses, then tap Start Preview in Streamwears.

Send feedback in Streamwears or through [support](https://streamwearsirl.com/support).
